## 一、实验背景与目标

### 1.1 核心问题

TerraState v2 模型在 checkpoint 11,904 步时因训练中断，恢复后继续训练至 14,880 步。需要通过严格同协议评测回答：

1. **恢复后的 14,880 步模型表现是否优于或等同于中断前的 11,904 步？**
2. **11,904 步的历史结果能否在新环境中完全复现？**（验证评测系统的确定性）
3. **14,880 步能否作为后续实验的正式 anchor checkpoint？**

### 1.2 评测协议

采用 TerraState Q1/Q2/Q3 三维评测体系：

- **Q1 (Forecast Accuracy)**: 预测精度，主要指标为 R² 和 RMSE
  - **Validation set**: 952 targets
  - **OOD-t (Out-of-Distribution Temporal)**: 1,904 targets
  
- **Q2 (State Load-Bearing)**: 状态承载能力，评估模型内部状态变量对预测的贡献度
  
- **Q3 (Extreme State Audit)**: 极端状态审计，84 对极端气候场景（hot-dry 等）
  - **endpoint_fidelity**: 终点保真度（模型是否准确预测极端状态）
  - **hotdry_enhancement**: hot-dry 增强效应（模型是否捕获极端气候下的非线性交互）

### 1.3 检验点标识

- **legacy-boundary11904@v1**: SHA `644deaac...`，中断边界点
- **verified-resume14880@v1**: SHA `a5d2a0cc...`，恢复后 checkpoint

| Checkpoint | overall_status              | endpoint_fidelity | hotdry_enhancement |

| **11,904** | Q3_RESPONSE_FIDELITY_ONLY   | **PASS**          | **FAIL**           |

**Q3 裁决细节**:

- **endpoint_fidelity (终点保真)**: 两个 checkpoint 均 **PASS**
  - 模型能够准确预测极端状态的终点响应
  - 84 对极端-对照配对的 bootstrap 检验均显著（CI 不含 0）
  
- **hotdry_enhancement (热旱增强)**: 两个 checkpoint 均 **FAIL**

**关键发现**:
- 11,904 和 14,880 在 Q3 上的裁决**完全一致**
- 继续训练未改变模型对极端气候的非线性交互能力

## 四、决策与结论

### 4.1 核心决策

**✓ 14,880 步 checkpoint 被正式接纳为后续实验的 anchor**

**决策依据**:

1. **Q1 表现等效**: 与 11,904 步在 validation 和 OOD-t 上无实质差异（Δ < 0.001）
2. **Q3 裁决一致**: 两个 checkpoint 在极端状态审计上完全同构
3. **训练连续性**: 14,880 步是 11,904 步的自然延续，无超参数变化
4. **历史复现通过**: 评测系统确定性得到验证，结果可信

### 4.2 关键约束

**0.01 阈值仅为描述性参考，非选择门**

- 早期文档曾提及"Validation R² 提升 > 0.01 才接纳新 checkpoint"
- **本次实验明确废除此硬性规则**
- 原因：
  - R² 在 0.497 附近的微小波动（< 0.001）不具备统计学意义
  - 0.01 阈值过于武断，无理论支撑
  - 应综合 Q1/Q2/Q3 多维评测，而非单一指标

**不根据 OOD 结果回选**

- 即使 OOD-t 表现略降，也不回退至 11,904
- 理由：
  - OOD-t R² 差异仅 0.00007，在噪声范围内
  - 14,880 步代表更多训练信号的积累
  - 回选会引入"事后挑选最佳点"的偏差

### 4.3 Q3 FAIL 的科学解读

**Q3 hot-dry FAIL 是科学结果，非工程问题**

- 当前模型架构（可能是状态空间设计、损失函数或训练数据）**未能学习到**极端气候下的非线性增强效应
- 这标志着模型的**能力边界**，为后续改进指明方向：
  - 增强极端样本的训练权重
  - 引入显式的极端气候先验（如物理约束）
  - 探索新的状态表征方式

- **不应因 Q3 FAIL 而拒绝 14,880 checkpoint**
  - Q3 裁决在两个 checkpoint 间一致，说明这是模型固有属性
  - 拒绝 14,880 等价于拒绝整个训练轨迹，无意义

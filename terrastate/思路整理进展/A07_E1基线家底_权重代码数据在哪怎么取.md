## 3. 移植方案：已有成功模板

`terrastate/models/encoders/contextformer_official.py` 是 Contextformer 的
**vendored、无依赖**移植，文件开头写明了做法：

> 只拷 `nn.Module`（不要 Lightning、不要 emp 包）；模型本体是纯 torch + timm，
> 在 torch 2.x 上跑得动。`Attention` / `Mlp` / `LayerScale` / `Block` /
> `get_sinusoid_encoding_table` / `PVT_embed` / `ContextFormer.forward` 逐字复制；
> 仅内联 `inverse_permutation`、去掉 `add_model_specific_args`。

**ConvLSTM / PredRNN / SimVP 照此办理即可**，且它们比 Contextformer 简单得多
（纯卷积/循环，无 PVT 编码器）。

本机**没有 `gh` 也没有 token**，无法创建 GitHub Release。可选：

| 方案 | 说明 |
|---|---|
| **A（当前采用）：只记录，不托管** | Zenodo 是公开永久源，本文档记了 record ID、zip SHA 与 12 个文件的逐个 SHA，可完整校验。换机器 `wget` 即可。**零成本、零配额消耗。** |

| C：GitHub Release | 需要 `gh` + token，本机不具备。 |

**除非有明确理由，建议维持方案 A。** 官方权重本就有公开永久归档，我们再存一份只是增加维护面。

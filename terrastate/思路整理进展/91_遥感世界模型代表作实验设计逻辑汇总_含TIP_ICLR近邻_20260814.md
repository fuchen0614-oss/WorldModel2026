## 1. 遥感世界模型六大类任务与代表作

### 1.0 六大类别总览

| 类别 | 一句话 | 主流度 | TerraState 位置 |
|---|---|---|---|
| **A. 空间外推与世界补全** | 中心影像+方向→邻接区域 | 新兴，2025 才起 | ❌ 不做 |
| **B. 时间预测与动力学推进** | 历史+未来驱动→未来地表 | **绝对主流** | ✅ **主线** |
| **C. 替代驱动情景模拟** | 换未来驱动→看轨迹变化 | 主流第二支柱 | ✅ **Q3 在此** |
| **D. 部分观测下状态估计** | 云遮挡/缺帧下恢复状态 | 成熟但常归为表征学习 | 🔶 有资产未兑现 |
| **E. 语义世界理解与未来事件** | 预测未来事件/风险，不只像素 | 上升期 | 🔶 最佳扩展方向 |
| **F. 不确定性与多种未来** | 输出分布而非平均图 | 气象侧成熟，EO 侧刚起 | ❌ 当前确定性 |

**核心结论**：
- **主流是 B+C 组合**（事实预测+情景响应+消融）
- EarthNet2021 系 / EO-WM / VegSim / VegeDiff **全部 0 个传统下游任务**
- TerraState 属 B+C，差异点是 Q2 的可证伪状态承载测试

### 1.1 类别 B：时间预测与动力学推进（**绝对主流**）

| 代表作 | 发表 | 任务 | 数据 | 下游任务数 |
|---|---|---|---|---:|
| **EarthNet2021** (Requena-Mesa et al.) | NeurIPS Datasets'21 | 历史 S2 + 未来天气 → 未来 S2 (NDVI/RGB/NIR) | EarthNet2021（32k minicube，欧洲） | **0** |
| **GreenEarthNet / Contextformer** (Benson et al.) | arXiv 2024 | 同上，强化 OOD-t | GreenEarthNet（19k，欧洲，含 ood-t/ood-s/ood-st） | **0** |
| **EO-WM** (Han et al.) | arXiv 2025 | 历史 S2 + 未来 ERA5 → 未来 RGB+NIR | 自建（全球多点） | **0** |
| **VegSim** (Zhou et al.) | arXiv 2025 | 历史 S2 + 天气/地形 → 未来植被 | EarthNet2021X | **0** |
| **ViT-Koop** (Shinohara et al.) | ICCV Workshop 2025 | 同上 + Koopman 压缩状态 | EarthNet2021 / BigEarthNet | **0** |
| **VegeDiff** (Zhang et al.) | TGRS 已发表 | 扩散模型预测未来植被 | EarthNet2021X（唯一数据族） | **0** |

**共同点**：
- 主任务都是**未来影像/指数预测**，输入必含未来驱动（天气）
- **全部 0 个传统下游任务**（无分割/检测/分类）
- 评测靠：①事实预测精度；②OOD 泛化；③消融；④天气/极端响应分析
- VegeDiff 证明了**单数据族 + 深度实验能在 TGRS 发表**

### 1.2 类别 C：替代驱动情景模拟（**主流第二支柱**）

| 代表作 | 机制 | 情景设置 |
|---|---|---|
| **VegSim** | 情景 rollout | 固定历史，换未来降雨/温度轨迹 |
| **TerraState Q3** | 替代 forcing | hot-dry / matched donor / normalized mean |
| EO-WM | 天气扰动响应 | 输出层响应诊断 |

**共同点**：都把"换天气看输出变化"作为**机制证据**，而非精度竞争。

### 1.3 类别 A：空间外推（新兴，2025 才起）

| 代表作 | 发表 | 任务 |
|---|---|---|
| **RemoteBAGEL** (Kondmann et al.) | arXiv 2025 | 中心 tile + 方向指令 → 邻接 tile |

评测：RSWISE 数据集（视觉真实性 + 方向指令服从性）。**与 TerraState 主线无交集。**

### 1.4 类别 D：部分观测状态估计

**任务形式**：云遮挡/缺帧下恢复完整状态或影像；S1↔S2 跨模态补全。

**代表数据集**：SEN12MS-CR（云去除）、UnCRtainTS（S1+S2 时序补全）。

**与世界模型的关系**：常被归为表征学习或图像复原，但**逻辑上应属世界模型的一支**——因为它需要建模"部分观测 → 潜在完整状态"的推理。

**TerraState 的位置**：摘要写 "infers a spatial predictive state from cloud-masked histories"，但**没有任何实验以云遮挡为自变量**。这是一个未兑现的主张。

### 1.5 类别 E：语义世界理解与未来事件（上升期）

| 代表作 | 任务 | 数据 |
|---|---|---|
| **RS-WorldModel** (概念论文) | 未来事件预测（灾害/变化） | 未指定具体实现 |
| DynamicEarthNet (Toker et al., CVPR'22) | 每日影像 → 月度语义变化 | 75 AOI，2 年，Planet + 人工标注 |

**为什么重要**：这是唯一"既是世界模型任务（有未来指向），又有独立语义标注（非 NDVI 派生）"的公开数据集。

### 1.6 类别 F：不确定性与多未来

| 代表作 | 机制 |
|---|---|
| VegSim | 概率预测 + 分布评测（CRPS） |
| VegeDiff | 扩散模型，采样多条轨迹 |

**TerraState 当前是确定性模型**，不在此类。

## 2. 代表作的实验设计逻辑

### 2.1 EarthNet2021 系（EarthNet2021 / GreenEarthNet / Contextformer）

**主任务**：历史 10 帧 S2（50 天）+ 未来 100 天天气 → 未来 20 帧 S2（100 天）。

**评测指标**：
- 主表：R² / RMSE / NSE / MAE / SSIM（前三项最重）
- 按土地覆盖类分层
- 按预测时域分层（early / late / RMSE_25）

**消融**：
- 无天气 vs 有天气
- context-only vs context+weather
- 不同骨干（ConvLSTM / PredRNN / SimVP / Earthformer / Contextformer）

**OOD 设置**：
- IID（随机划分）
- OOD-t（时间：训练 2016–2019，测试 2019–2020）
- OOD-s（空间：训练欧洲西部，测试东部）
- OOD-st（时空联合）
- extreme / seasonal（特殊子集）

**下游任务**：**0 个**。

**GreenEarthNet 的独特贡献**：
- 重构更严格的 OOD-t split（排除泄漏）
- 引入 Contextformer（6M 参数，context-only 架构）作为强 baseline
- 证明 OOD-t 是比 IID 更有区分度的基准

**VegeDiff（TGRS）证明的路径**：
- 唯一数据族：EarthNet2021X
- 唯一主任务：未来 NDVI 预测
- 靠什么撑住：①扩散模型方法创新；②逐时域分析；③降水扰动响应；④多指数（NDVI/EVI/SAVI/MSAVI）；⑤效率对比；⑥消融深度；⑦定性图
- **0 个传统下游**

### 2.2 EO-WM（Han et al., arXiv 2025）

**主任务**：全球多点 S2 时序 + ERA5 天气 → 未来 RGB+NIR。

**实验设计**：
- 事实预测精度（主表）
- 跨区域泛化（训练某洲、测试另一洲）
- **天气响应诊断**：输出层对天气变量的梯度敏感性
- 极端天气案例（热浪/干旱/洪水）
- 消融：天气编码器、时域长度、地理编码

**下游任务**：**0 个**。

**与 TerraState 的差异**：
- EO-WM 做输出层响应诊断；TerraState 做状态路径移除（Q2）+ 替代 forcing（Q3）
- EO-WM 全球多点；TerraState 单区域（欧洲）但有 OOD-t/s/st 完整矩阵

### 2.3 VegSim（Zhou et al., arXiv 2025）

**主任务**：未来植被模拟。

**实验设计**：
- 事实预测（R² / RMSE / MAE）
- **情景 rollout**：固定历史，替换未来降雨/温度轨迹，看预测如何变化
- 极端天气响应（干旱/热浪）
- 概率预测 + CRPS / 覆盖率
- 消融：天气编码、地形、初始条件

**下游任务**：**0 个**。

**与 TerraState Q3 的关系**：
- VegSim 的情景 rollout 与 TerraState Q3 属同一范式（替代 forcing）
- 差异：VegSim 滚动多步，TerraState Q3 单次 horizon 查询；VegSim 概率，TerraState 确定性

## 3. TIP 遥感/视频预测近邻

**Codex 已调研**（`01_转期刊_TIP与TGRS路线_20260813.md`）：TIP 是**图像/视频/多维信号处理**期刊，遥感只是应用之一。

### 3.1 TIP 接收的遥感时序类论文（近年实例）

| 标题（简化） | 年份 | 任务 | 方法 | 实验设计 |
|---|---|---|---|---|
| TTST: Temporal–Spectral Transformer | 2023 | 时序 HS 影像融合 | Transformer | 3 数据集 + PSNR/SSIM/SAM/ERGAS + 消融 + 可视化 |
| STC-GAN: Spatiotemporal Cloud Removal | 2022 | 云去除（时序） | GAN | 多数据集 + 图像质量指标 + 对比 SOTA |
| Deep Memory Network for RS Video Semantic Segmentation | 2021 | 视频分割 | 记忆网络 | 标准语义分割基准 + mIoU |

**共同特征**：
- 都做**标准图像任务**（融合/去云/分割），报**标准图像指标**（PSNR/SSIM/mIoU）
- 多数据集（2–3 个）
- 方法首先是图像/视频处理贡献
- **没有看到 TIP 接收"世界模型式"的外生条件预测论文形成稳定范式**

**Codex 的关键观察**：TIP 更常用 `video prediction / temporal modeling / conditional generation / state-space representation` 这类图像处理语言。**"world model"可以是上层定位，但不能替代标准图像任务和结果。**

### 3.2 若投 TIP，TerraState 需要补什么

按 Codex 判断：

1. **多光谱/多通道输出** + PSNR/SSIM/LPIPS/SAM —— 把 NDVI 单通道升级为 RGB+NIR（**分水岭**）
2. 第二、第三个数据集（实践上 2–3 个）
3. 定性图像证据（预测序列、误差图、纹理细节、极端案例、失败案例）
4. 重构叙事为"外生条件时空影像的预测状态学习"，把"天气"抽象为一般外生变量

**或者选 TGRS**（Codex 推荐）：VegeDiff 已证明单数据族 + 深度实验能过 TGRS，且不需要多光谱改造。

## 4. ICLR 世界模型/表征学习近邻

**Codex 已核实 ICLR 2026 Reviewer Guide**：核心问题是论文是否给社区带来新知识与足够价值，要求动机充分、技术正确、实验严谨、主张受证据支持，**不要求刷 SOTA**。征稿范围明确含表征学习、组合建模、结构预测、不确定性。

### 4.1 ICLR 接收的世界模型类论文（近年趋势）

| 主题 | 代表 | 核心贡献 |
|---|---|---|
| 可组合世界模型 | IRIS / Dreamer v3 | 学习可组合的状态转移 |
| 可干预表征 | PLSM | 简化状态空间，使动作效应可测量 |
| 预测性状态表征 | I-JEPA / V-JEPA | 不重建像素，学习预测性表征 |
| 评测协议 | Vafa et al. 2024 | 自动机支配的生成模型评测 |
| 视频世界模型 | Genie / GameNGen | 像素级互动世界模拟 |

**遥感具体实例较少**，但 ICLR 接收的**气候/地球系统模型**论文证明领域可行：
- FourCastNet（天气预报 Transformer，ICLR'23 Workshop）
- ClimaX（气候基础模型，NeurIPS'23，作者群与 ICLR 社区重叠）

### 4.2 ICLR 路线对 TerraState 意味着什么

**当前优势**：
- Q2（状态承载性可证伪测试）是方法论贡献，不只是应用
- Q3（替代 forcing 响应保真度阶梯）是诚实的协议创新
- 不需要刷 SOTA

**需要补的**（按 Codex 判断）：

| 缺口 | 为什么 ICLR 需要 | 如何补 |
|---|---|---|
| **可组合转移** | Q4 不成立暴露了这个缺口 | 改模型成递归状态转移 + composition 进训练目标 |
| **干预校准** | Q3 只证明"输出会变"，不证明"变得对不对" | 成对情景监督（模拟器 + 真实 EO 多保真对齐） |
| **跨模型机制测量** | 证明"精度 ≠ 状态承载性"是普遍现象 | 在多个模型上测同一套状态/响应指标 |

**Codex 推荐的 ICLR 叙事**（候选 C）：

> 不宣称从纯观测恢复真实因果世界，而是提出一种**多保真、干预感知的遥感预测状态世界模型**：在真实 EO 上保持事实预测，在受控情景上学习并验证替代天气响应，能向未见驱动轨迹外推。

**三层数据证据结构**：
1. 真实 EO（事实预测锚点）—— GreenEarthNet 继续用
2. **过程模拟器**（同初态多驱动的成对轨迹）—— WOFOST/PCSE+SCOPE（植被线首选）或 SFINCS（洪水线）
3. 真实干预/自然实验（外部合理性检查）—— DroughtNet / IDE

## 5. 关键结论：别人怎么做、我们可以借鉴什么

### 5.1 遥感世界模型的共识

| 共识 | 证据 |
|---|---|
| **主任务是未来预测，0 个传统下游是常态** | EarthNet2021 / GreenEarthNet / EO-WM / VegSim / VegeDiff 全部如此 |
| **单数据族 + 深度实验能发期刊** | VegeDiff（TGRS）唯一用 EarthNet2021X |
| **OOD 设置比多数据集更重要** | GreenEarthNet 的 ood-t/s/st 完整矩阵是其核心贡献 |
| **机制证据靠消融 + 天气/极端响应，不靠下游任务** | 全部代表作都这么做 |

### 5.2 TIP vs ICLR 的本质差异

| | TIP | ICLR |
|---|---|---|
| 遥感论文形态 | 标准图像任务 + 图像质量指标 | 可以是 NDVI 单通道 |
| 增量来源 | 广度（多数据集、多指标、定性图、多种子） | **深度**（方法创新、协议创新、机制洞察） |
| 下游任务 | 期刊期待（虽然 VegeDiff 证明不是必需） | 不关心 |
| 改模型 | 可不改（除了多光谱） | **必须改** |

### 5.3 对 TerraState 的三条建议

**若走期刊线（TGRS / TIP）**：
- 对标 VegeDiff 的路径：单数据族 + 完整 OOD 矩阵 + 深度分层 + 云遮挡/LC/lead-time 分析 + 定性图 + 训练级消融
- TGRS 不需要多光谱改造；TIP 需要

**若走 ICLR**：
- 对标 I-JEPA / PLSM 的方法论路径：可组合 + 可干预 + 协议创新
- 必须改模型补上 Q4 缺口
- 用模拟器提供干预校准的成对监督

**共用层（两条路都要）**：
- 完整 OOD 矩阵（iid / ood-t / ood-s / ood-st）
- 四维分层（云 / 帧数 / lead-time / LC）
- 训练级 4-arm 消融
- 跨模型机制测量（至少 Contextformer + B4）

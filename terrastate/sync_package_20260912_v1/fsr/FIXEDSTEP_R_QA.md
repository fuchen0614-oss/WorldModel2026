## 1. 我到底改了什么？为什么必须改代码？

**必须改代码**（已实测确认，不是猜测）：

- trainer 的 `--arm` 只接受 `C1/C0R`（`train_terrastate_candidate_c.py:673`），`--factual-path` 只接受 `recursive/direct`（:675）；

**改动范围：3 个文件、7 处、全部在独立副本里，共享代码零改动。**

| 文件 | 改动 |

| `models/terrastate_candidate_c.py` | ①`factual_path` 白名单加 `fixed_step`；②新增 `fixed_step_partition(ep)`（由 `days_per_transition_step=5` 推导）；③`draw_endpoint_plan` 增加 `fixed_step` 分支 |

## 6. 必须如实登记的两项偏离

1. **算力不对称（对 C1 略有利）**：FSR 每步固定 9 次 transition，C1 期望 8.005 次（6–10 波动），比值 **1.1243**。

2. **机器不同**：C1/C0R 正式臂在 `csy-zg01-gnode39`，FSR 在 dilab。world/accum/seed/数据/父权重均已对齐，但机器差异无法消除，按既有惯例"如实登记、不修正"。

## 11. "训练确实走固定五日步"的一手取证（真实数据 + 同一条损失函数）

`eval/verify_loss_path.py` 不做任何模拟：它用**真实数据集与真实 collate**，直接调用 trainer 训练时
调用的同一个 `loss_candidate_c`，打印它实际使用的端点分区。实测输出：

```text
=== FSR smoke checkpoint (fixed_step)
    factual_path = fixed_step
    endpoint_logs = [(10, (5, 5), 2), (15, (5, 5, 5), 3), (20, (5, 5, 5, 5), 4)]
    total_segments_this_step = 9

=== C1 formal checkpoint (recursive, control)
    factual_path = recursive
    endpoint_logs = [(10, (5, 5), 2), (15, (7, 4, 4), 3), (20, (10, 5, 5), 3)]
    total_segments_this_step = 8
```

结论：
- FSR 的端点监督**恒为** (5,5) / (5,5,5) / (5,5,5,5)，即每步 2+3+4 = **9 次 transition**；
- 同一份代码加载 C1 权重时仍**抽签**取多段（本例 (7,4,4) / (10,5,5)，共 8 次）→ **既有臂零回归**；
- 这也直观显示了算力不对称：9 vs 8（期望值 9 vs 8.005，比值 1.1243）。

> 训练结束后用正式权重重跑会追加一行 `FSR FORMAL checkpoint`，届时该文件即为最终取证。

## 14. 诚实解读：这些数据对论文主张意味着什么

> 本节只做**由已落盘数值直接支持的推断**；凡是尚未测的（共同后缀、效率、显著性），一律写成"未测"。

### 14.1 现在能确定的三件事

1. **直接端点监督（C0R）确实不行**：它的留出组合比值约 1.07–1.32，**全部超出 0.05 容差**。
   → "端点监督必须经过某种递归路径"这一点，本轮数据仍然支持。
2. **固定五日步递归监督（FSR）与 C1 在"换分段方式"的稳健性上没有可分辨差距**：
   dev476 composed/direct 最差比值 FSR **1.026722** vs C1 **1.027497**；
   iid2856 FSR **1.039562** vs C1 **1.023419**；四组各 9 个组合，**两边 9/9 全部在容差内**。
   → 现有证据**不能**支持"必须是**变跨度**递归监督才能获得分段稳健性"。
3. **标准预测上 FSR 还略好**：四个 split 的 R² 高 0.18%–0.40%、RMSE 低 0.05%–0.11%
   → C1 在单次预测精度上**没有**相对固定步长递归的优势（幅度很小且未做显著性检验）。

### 14.2 因此，主张需要收窄到哪里

| 原本可能想写的 | 本轮数据支持吗 | 建议写法 |
|---|---|---|
| "递归端点监督优于直接端点监督" | ✅ 支持（C0R 明显失效） | 可保留 |
| "**变跨度**递归监督是分段稳健性的来源" | ❌ **不支持** | 必须删除或降级为"未证实" |
| "TerraState 的变跨度跳跃带来预测质量优势" | ⚠️ 未观测到 | 只能说"不劣于"，不能说"优于" |
| "固定步长递归天然支持续推、所以需要更强的主张" | ⚠️ 反而被本轮加强 | 需要正视：FSR 也具备续推能力且稳健性相当 |

**剩下真正可能站得住的差异点**只有：**成本与灵活性**——即在同等稳健性下，C1 用更少的 transition 调用（期望 8.005 vs FSR 固定 9）完成跨跨度查询。
这必须由共同后缀 + 效率实测来支撑（本报告 §13.3/§13.4，进行中）。**如果这两项也打平，则"变跨度"的独立价值就没有实验支撑，需要回到方法或降低主张。**

### 14.3 必须同时声明的限制

- **单 seed（42）**：以上差异均未做跨种子稳健性检验。
- **未做显著性**：标准预测差异（0.05%–0.40%）未做空间 tile 配对 bootstrap，不能宣称显著。
- **算力不对称**：FSR 每步 9 次 transition，C1 期望 8.005 次（+12.4%）。
  这**有利于 FSR**；既然 FSR 没有因此明显胜出，也不能反过来说"FSR 更省算力"。
- **Q2 门按合取判定**：FSR 在 36 个移除臂中仅 1 个跨零即整体 FAIL；该臂是 FSR 未见过的 `(5,3,2)` 分段。
  报告时应给出**未校正**读法，并按 A14B 要求说明多重比较问题，不能只说"FSR FAIL"。
- **dev476 是开发诊断集**，不是独立泛化证据；iid2856 才是独立确认集。

### 14.4 共同后缀：iid 上分开，ood-t 上不重复（必须两个都报）

共同后缀（10→20，同一后续天气）下，A = 直达 10 接后缀，B = 分段到 10 接同一后缀。

| 指标（h=10） | iid: C1 / FSR | ood-t: C1 / FSR |
|---|---|---|
| A 路径 pooled RMSE | 0.193490 / **0.191016** | 0.166642 / **0.165858** |
| B 路径 pooled RMSE | 0.193543 / **0.192157** | 0.167271 / **0.166352** |
| **A/B 差距（B−A）** | **+0.000053** / +0.001141 | +0.000629 / **+0.000494** |
| **平均 A−B 输出 MAE** | **0.006496** / 0.009020 | **0.006545** / 0.008829 |
| 平均 A−B 原始状态 L1 | 0.172600 / 0.137659 | 0.173542 / 0.137669 |

**读法（不夸大）**：
- **绝对精度一致偏向 FSR**：两个 split 的 A、B 路径 pooled RMSE 都是 FSR 更低。
- **A/B 的 pooled-RMSE 差距不稳定**：iid 上 C1 小约 21 倍，**ood-t 上反而略大**；
  逐 horizon 看，C1 在 ood-t 的 h=3–6 仍更小，h=7–10 收敛。→ **该统计量是 split 相关的，不能单独作为结论。**
- **A−B 输出 MAE 在两个 split 上一致偏向 C1**（0.00650 vs 0.00902；0.00655 vs 0.00883，约小 26%）
  → 这是目前**唯一跨 split 一致**的相容性信号，仍需其余两个 split 与配对 bootstrap 确认。
- **原始状态距离不是功能判据**：两个 split 上 FSR 的两路径状态 L1 都更小（0.1377/0.1377 vs 0.1726/0.1735），
  输出差异却更大 —— 直接支持 A13/REVIEW 的立场，也说明共同后缀确实测的是别的东西。

### 14.5 一句话给决策

> 固定步长递归对照**没有在标准预测与留出分段稳健性上把 C1 分开**（FSR 甚至略好）；
> 在共同后缀上，**绝对精度依旧偏向 FSR**，而**路径相容性的两个统计量给出不同答案**：
> pooled-RMSE 差距 split 相关（iid 偏 C1、ood-t 略偏 FSR），**A−B 输出 MAE 两个 split 都偏 C1（约小 26%）**。
> **因此目前能说的是"变跨度监督可能提升路径相容性"，还不能说"已证实"**——
> 需要 ood-st / ood-s 两个 split 与配对 bootstrap 才能定论。
> 必须并列报告：FSR 绝对精度略好、留出稳健性两者无差别、FSR 在 36 个 Q2 移除臂中有 1 个不通过。

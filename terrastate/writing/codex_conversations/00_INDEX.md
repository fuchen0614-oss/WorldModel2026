## 已经定下来的几条（从对话中提炼，供快速对齐）

**期刊路线**

- Codex 的判断：最合理的备选**不是 TIP 而是 TGRS**。TIP 不是遥感专业期刊，是图像/视频/多维信号处理期刊，遥感只是应用之一。
- 建议顺序：**首投 TGRS → 扩展完整但效果一般转 JSTARS → 跨区域与应用结果强再考虑 ISPRS JPRS**。
- 若坚持 TIP，需要把方法一般化（加非遥感视频或天气雷达数据、PSNR/SSIM/LPIPS、时序一致性、通用图像预测基线、FLOPs/延迟、完整消融），这已接近另一篇论文，不适合作为"AAAI 没中后的快速备选"。
- 我本人的倾向是**仍想往 TIP 靠**，这一点在对话里反复出现，需要接手方注意这个张力。

**下游任务**

- 加下游任务**不是必须**。已发表先例（GreenEarthNet/Contextformer CVPR 2024、VegeDiff TGRS）都只用一个主要数据集族，靠大量基线、OOD 分层、消融、多种子和统计检验把实验做完整，并未硬接土地覆盖等无关下游。
- 只有当论文自称 foundation model / 通用表征 / universal EO model 时，多下游任务才近乎硬要求。
- 我给自己定的任务描述是：「在 AAAI 论文基础上做下游任务的可验证分析，包括洪水检测、地表变化、城市扩张、时序预测等，目标一篇期刊论文；同时修改模型框架，结合不同数据将反事实推演能力纳入模型性能，扩展任务边界，目标 ICLR。」——这条需要和上面"下游不是必须"的结论一起权衡。

**两条线**

- 路线 A（TerraState 世界模型）与路线 B（Stage1→1.5 多模态表征）**同步推进但暂不合并**。
- 理由：两条线回答的问题不同；Stage1–1.5 的非线性成像条件泄漏尚未解决、下游价值尚未证实，强行合并会让主张比证据走得更远。

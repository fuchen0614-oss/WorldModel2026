## A. 补充实现细节

### A.1 上下文隔离与预测状态构造

在预测起点 `t`，光学上下文记为 `H_t = {(x_i, m_i, τ_i)}，i = 1,…,C`，其中 `x_i` 是 Sentinel-2 合成影像，`m_i` 是有效性掩膜，`τ_i` 是获取时间。历史气象、按时间排序的未来气象、静态地理信息和未来光学目标分别记为 `u_past(≤t)`、`u_(t+1:t+H)`、`g` 和 `y_(t+1:t+H)`。上下文 `C̃_t = (H_t, u_past(≤t), g)` 不包含未来光学观测或未来气象。

每个 minicube 含 30 个五日合成时刻，空间尺寸为 `128 × 128`。前 10 个时刻为上下文，后 20 个时刻构成 100 天预测窗。光学输入含 NDVI 和 4 个反射率波段；8 个气象变量分别按均值、最小值和最大值聚合为 24 个通道；静态输入有 5 个通道，其中前 3 个高程产品用于逐 patch 地理条件。

历史算子采用 TerraState 所使用的 PVT v2/Contextformer 配置。`4 × 4` patch 产生 `32 × 32 = 1,024` 个空间 token。投影器在每个最终上下文 token 上依次应用层归一化、两层多层感知机和输出归一化。每个 minicube 的状态尺寸为 `[1024, 256]`，批和 patch 展平后为 `[1024B, 256]`。

上下文约束由计算图保证：历史前向前将未来光学张量和未来气象置零，并由历史算子屏蔽未来影像位置。因此，上下文预测与初始状态只依赖历史观测、过去气象和静态地理信息，使后续天气替换仅作用于状态转移。

### A.2 直接共享转移与状态读出

每个预测时域都以有序未来气象前缀为条件。共享门控循环单元在一次循环前向中产生全部 20 个前缀编码；地理编码器把三个高程通道平均池化到 `4 × 4` patch 网格，正弦嵌入表示预测时域。融合网络与残差转移在所有 patch 和时域间共享参数；地理条件保留 patch 差异，天气与时域编码广播到整个 patch 网格。

所有预测时域均从同一个历史状态 `z_t` 直接查询。模型针对每个 `h` 使用前缀 `u_(t+1:t+h)` 执行一次共享转移，不把 `z_(t+h−1)` 递归输入下一时域。状态读出将每个 256 维推进 token 映射成局部 `4 × 4` 输出 patch，并重组为 `r_h ∈ R^(1×128×128)`。状态贡献系数是固定为 1 的不可学习缓冲量，为 Q2 提供明确切点。

### A.3 训练目标构造

真实目标损失先在每个像素的晴空时刻上平均平方误差，再对合格植被像素平均。冻结的全天气知识蒸馏（knowledge distillation, KD）教师提供停止梯度的预测目标，在完整目标中的权重为 0.5。

未来状态目标只锚定终端推进状态：训练开始时冻结的历史算子与投影器副本处理包含真实掩膜的全时段光学序列，并将未来气象置零。只有完全晴空且至少含一个植被像素的终端 `4 × 4` patch 参与层归一化 token 的余弦距离。未来光学观测仅构造停止梯度的训练目标，不进入部署推理图。训练结束后丢弃教师与目标编码器，Q2、Q3 不引入额外训练目标。

## B. 训练与评测协议

### B.1 训练与实现细节

| 设置 | 数值 |
|---|---|
| Epochs / 优化器更新次数 | 40 / 14,880 |
| 优化器 | AdamW |
| `β₁, β₂` / 权重衰减 | `0.9, 0.999` / 0 |
| 非历史分支 / 历史算子学习率 | `3 × 10⁻⁵` / `9.9 × 10⁻⁷` |
| 学习率日程 | 300 次更新预热，随后余弦衰减 |
| 全局 batch | 64（8 个设备 × 每设备 8 个样本） |
| 梯度累积 | 无 |
| 梯度裁剪 | 全局范数 1.0 |
| 数值精度 | FP32 |
| 硬件 | 8 块 NVIDIA H200 GPU |

*表 1：TerraState 训练配置。学习率分别对应非历史分支和历史算子参数组。*

最终模型完整训练 40 epochs，共 14,880 次优化器更新。训练使用 AdamW，`β = (0.9, 0.999)`，权重衰减为 0，梯度全局范数裁剪为 1.0。非历史分支基础学习率为 `3 × 10⁻⁵`，历史算子参数组学习率为 `9.9 × 10⁻⁷`。学习率先线性预热 300 次更新，再做余弦衰减。

前 20% 更新中，历史算子冻结，`λ_s` 从 0 线性增加至 0.02；20%–80% 阶段历史算子继续冻结，`λ_s = 0.02`；最后 20% 只解冻历史算子的最后一个 Transformer block，且 `λ_s = 0.01`。其余 TerraState 分支全程优化。

全局 batch 为 64，由 8 块 NVIDIA H200 GPU、每卡 8 个样本组成，不使用梯度累积，数值精度为 FP32。模型仅依据验证集预测表现选择；Q2、Q3 与 OOD-t 均不参与选择。选定模型在不更新参数的条件下评测 Q1–Q3，从而保证干预结果不进入 checkpoint 选择或参数更新。

### B.2 GreenEarthNet 划分、预处理与评分

GreenEarthNet 提供独立的训练、验证和时间分布外划分。训练集用于优化，验证集用于模型选择和 Q2 验证分析，OOD-t 不参与模型选择。OOD-t 含 1,904 个 minicube。Q2 的验证评分集含 952 个目标 minicube，其中 589 个在评分器资格规则后形成配对指标单元。

数据适配器每五天采样一次光学记录。NDVI 由近红外和红光反射率计算。缺失光学值在独立构造云与质量掩膜后置零；晴空规则结合给定学习式云掩膜和有效场景类别。气象变量用 GreenEarthNet 统计量归一化，并按均值、最小值和最大值聚合为 24 个通道。高程通道除以 500，类别静态层保持原尺度。

预测目标是有效植被像素上的 NDVI，输出张量尺寸为 `[B, 20, 1, 128, 128]`。文件式评分输出保存目标时间戳上的 20 个 NDVI 预测及原始经纬度坐标。官方评分器先计算像素级时间序列量，再在 minicube 与植被地表类别间平衡汇总，输出正文第 4.1 节定义的 `R²`、RMSE、NSE、absolute bias 和 `RMSE₂₅`。

## C. Q2 干预与统计协议

Q2 在完全相同样本上比较三种前向计算。完整模型使用正文中的加性状态路径；状态移除在最终相加前将状态贡献置零，从而恢复上下文预测 `b_h`；恒等转移控制以未推进的 `z_t` 替代学习转移输出，同时保留状态读出。各分支的模型权重、历史、目标窗、掩膜和评分器均保持固定。

协议区分两个估计量。Official `ΔR²` 是完整模型与干预模型的数据集级分数之差；paired `ΔR²` 先在每个合格 minicube 上求差再平均，其 95% 百分位区间来自 10,000 次配对 bootstrap。由于两者聚合顺序不同，配对区间刻画的是平均逐 minicube 配对效应，而不是 official 数据集级差值。

状态移除比较提供主要证据：显式状态贡献在验证集和 OOD-t 上均带来可测量的预测增量。恒等转移为学习得到的状态更新提供补充证据，因此作为支持性而非主要证据。具体数值见正文表 2。

实现不变量检查保证各分支使用相同样本顺序、目标、掩膜、上下文预测和冻结参数；同时检查状态移除恢复 `b_h`、固定状态贡献系数在每次调用后恢复，以及 bootstrap 前有限配对单元严格对齐。

## D. Q3 热旱子集与天气控制协议

Q3 使用包含 84 个匹配对的冻结热旱子集。这 84 个评测样本是预先规定的热旱层中所有符合条件的 OOD-t minicube：热异常与旱异常阈值由训练气候分布的第 80 百分位估计，并在模型评测前冻结；合格样本还要求未来天气有效覆盖率至少为 80%。子集构造不使用未来 NDVI、模型预测、预测误差或 checkpoint 输出。

Donor 从正常天气池中选取，并在相同气象季节内执行确定性最近邻匹配。匹配距离是以下特征的标准化差值均方根：年内日期、纬度、经度、植被比例、上下文云比例、上下文有效比例、上下文 NDVI 均值和未来天气有效比例。匹配须满足 1.5 的 caliper，且每个 donor 最多重复使用 5 次。该冻结流程最终形成 84 个 pair，涉及 45 个唯一 donor 和 31 个地理 cluster。因此，“84 组”正是热旱筛选及其匹配控制的最终评测单元。

天气干预保持历史上下文、`b_(1:H)`、`z_t`、地理信息、时域查询、读出、目标窗和掩膜不变，仅替换提供给共享转移的未来天气：真实天气、冻结匹配 donor 天气，或冻结全局标准化空间中的归一化均值天气（全零张量）。

主损失是完整 20 步预测窗上的掩膜均方误差。逐 pair 计算 control-minus-actual loss，正值表示真实天气更优。不确定性分析对 31 个地理 cluster 有放回重采样 10,000 次，以保持 donor 重用导致的相关性。真实天气损失更低的 pair 数量仅作为描述统计，统计推断以地理 cluster bootstrap 为准。正文表 3 中的子集 `R²` 和 RMSE 专门对应这 84 个匹配样本。

该干预衡量冻结匹配协议下、基于观测目标的条件响应保真度。由于没有观测控制天气序列下的另一真实世界结果，因果和反事实识别超出该估计量的范围。

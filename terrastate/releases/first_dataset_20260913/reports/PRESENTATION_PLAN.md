# PRESENTATION_PLAN — 表图组织与展示方案

本文件回答三个问题：**先讲什么、哪些放正文、每项要强调什么又要限定什么。**
逐项的问题/结论/证据分层见 `reports/EVIDENCE_INVENTORY.csv`；
主张分层见 `reports/CLAIM_EVIDENCE_MATRIX.csv`（`evidence_role` 列）。

## 1. 主线

TerraState 通过**天气驱动的空间状态演化**与**递归路径事实监督**，
使中间状态在不同时间分段后**仍能接续预测**未来遥感影像。

## 2. 证据顺序

**预测基础 → 递归监督的分段收益 → 共同后缀接续能力 → 中间状态的信息作用 → 天气响应 → 可核实的运行成本**

先立住“能预测”，再讲“为什么这种训练方式更好”，然后给“状态确实承载未来信息”的直接证据，
再补天气响应与成本，最后把代价与限定一次说清。

## 5. 每项最值得强调的发现与必须一并说明的限定

| 项 | 最值得强调 | 必须一并说明的限定 |
|---|---|---|
| Table 3.3 | C1 九个留出分段比值 1.0005–1.0275 **全部落在门内**，C0R 1.0709–1.3246 全部超门 | 1.05 是 **MSE 比值门**，不是 5% RMSE；PASS **不等于**等价 |
| Table 6B | 四个 split 上 D20/A/B/donor 用**同一段后续天气与同一读出时刻**，完整可比 | **不是**逐步递归 rollout；donor 替换的是**状态**，不是天气 |
| Table 4B | 主口径 receiver 等权：完整后缀四 split 点估计全为正、CI 下界全 > 0 | 单终点 h10 上 OOD-st 的 receiver 等权 CI 下界 > 0 而**地理组等权 CI 跨 0**；**不得写“所有窗口、所有口径均显著”**；CI 条件于已固定的 donor 匹配方案 |
| Table 4A | 移除状态支路显著退化，配对 ΔR² 的 CI 不含 0 | 功能性检查，**不是**完整物理状态证明 |
| Table 5 | ΔLoss 两个比较均为正且 CI 不含 0 | 只覆盖冻结热旱子集；**响应幅度 ≠ 损失收益**（`dloss_donor` 不显著）；mean 对照是归一化置零 |
| Table 7 | 分阶段成本可复算；成本模型随 B 变化 | 受限测量（单机单卡、单样本、batch 1、共享节点）；**不报单一倍率**；适配器开销主要来自每次调用的全量 state-dict 哈希校验 |
| Table 3.2 | C0R 的 R²_LC 在四个 split 上一致略高 | 差异小（+0.0026 ~ +0.0049）；**不作非劣性判定**（边界从未定义） |
| Table 1 | C1 与已发布基线同协议并排 | 并非每项最优；均值±样本std（n=3）**不是**置信区间 |

## 7. 术语纪律（全包统一）

- 1.05 是 **MSE 比值门**，不是 5% RMSE；PASS 不等于等价。
- CI 跨零 **不等于**非劣；本包不做任何未检验的非劣性判定。
- 官方 **LC-balanced** 与 **pooled** 两条口径不可互换、不可跨表比较。
- 不使用“等效 / 非劣 / 不可替代 / 任意分段 / 连续时间 / 完整物理状态 / 真实反事实”等未经检验的表述。

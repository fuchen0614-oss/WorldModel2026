## 图件结构

图 1–9 的正式版本、备选、候选、数据、代码、中文图注和阅读解析只位于相应图号目录。当前本地目录以只读目录联接复用 `first_dataset_figures_final_20260913T052645Z`，不复制 449 MB 图件内容，也不改变终稿图包。

- `selected/`：正文当前采用版本；
- `alternatives/`：有效备选；
- `candidates/`、`contact_sheets/`：候选与接触表；
- `data/`、`code/`：该图的数据与重绘入口；
- `CAPTION_ZH.md`、`ANALYSIS_ZH.md`：可直接引用的图注与完整读图分析。

图 1/2 当前为文字框架；图 4 为第二数据集延期边界；图 3/5/6/7/8/9 均有正式 PNG/PDF。

## 其他目录

- `tables/`、`metrics/`、`manifests/`、`metrics_derived/`、`provenance/`：复用旧十二章母稿的冻结统计资产，供第一份文档逐项追溯。
- `references/`：A13、A14、A14B 与叙事复核材料的只读副本。
- `supplement/`：主文与完整十二章之间的使用说明。
- `reports/`：链接、措辞、图件与结构自查记录。

两份文档共用同一批冻结数值，但承担不同任务：第一份是完整结果总账，第二份是便于继续改写和翻译的正文母稿。

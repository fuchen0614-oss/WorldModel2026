# 图3阅读与结果分析

## 怎么看

先看A中的Ground truth空间结构，再逐行比较Persistence、四个官方基线和TerraState-C1；随后在B中查看同一方法、同一日期的绝对误差位置。A与B的行列严格对应，适合判断模型是在边界、纹理还是局部变化区产生误差。

## 横纵轴与颜色

横向四列是四个冻结五步窗口中的代表日期；纵向是方法。A的色带为NDVI 0–1，暗色较低、亮色较高。B的色带为绝对误差0–0.4，暗色表示误差低、亮色表示误差高；灰色只表示无效像素，不代表预测值或误差大小。

## 当前效果与结论边界

P42四个窗口都有有效观测，Persistence在变化区域出现较广的高误差，而不同学习方法呈现不同程度的平滑、纹理保留和局部偏差。四个官方基线（ConvLSTM 1M、PredRNN 1M、SimVP 6M、Contextformer 6M）均来自匹配的GreenEarthNet官方seed-42 checkpoint，图中已无空行。该图只说明单例空间行为，不能代替表1的总体排序。

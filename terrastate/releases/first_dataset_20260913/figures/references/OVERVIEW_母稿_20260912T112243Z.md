# 第一部分 · 研究主线与核心发现

## 1.1 我们研究的问题

遥感影像时间序列的未来观测由地表状态的演化决定。给定一段不完整、常被云遮挡的历史观测，再给定一段未来的天气驱动，模型要预测接下来的 NDVI 序列。这类预测的标准做法是把历史编码成表示，然后一次性读出未来若干步。

问题在于，**一次性预测准确并不等于内部状态可以继续使用**。一个模型完全可以在某个固定时距上把未来二十步拟合得很好，而它形成的中间表示只是这条端到端映射的一个副产品：换一个位置接续、或者把同一段未来拆成两段来计算，它未必还能给出同样可靠的预测。当前图像预测得对，并不能单独证明状态保留了"从这里继续往下推"所需要的信息。

这背后有一个具体的信息论事实。在本项目的实现里，每个空间位置的状态是 256 维向量，而读出到当前时刻 NDVI 的线性头只产生 16 个值（`models/plan_b_b4.py` 的读出定义），因此读出矩阵的秩至多 16，至少有 240 个方向无法由当前输出确定。这只是一个**非唯一性**的维度计数：它说明"当前预测正确"在原理上约束不到那些方向，并不说明那些方向真的存了有用的记忆。究竟存没存，只能由实验回答。

由此，本文的工作问题可以写成：

> 在部分可观测的高分辨率遥感影像序列中，能否学习一种**空间预测状态**，使天气条件的预测在改变推进跨度或时间分段之后仍然保持可靠，并使到达中间时刻的状态继续承担后续预测？

对应地，研究要回答两个彼此不同的问题：

- **组合问题**：沿不同的计算路径到达同一个时刻，输出是否相容？
- **预测记忆问题**：这些中间状态是否仍然保留着支持下一阶段预测的信息？

终点图像彼此相似只能部分回答第一个问题。要把第二个问题问清楚，必须给两条路径接上**同一段后续天气**，再看它们能否继续作出准确预测。这是本文实验链条的核心动机，也是后面第六章至第七章的设计由来。

## 1.2 研究定位

TerraState 属于**天气驱动的遥感世界模型**研究：它从历史观测推断内部状态，在外部驱动下演化，并读出未来观测。我们把这一归属保留为研究背景，但论文的论证重心不放在"它算不算世界模型"上，而放在**状态在时间推进上的可用性**这件事上。

具体的方法取向是：**面向不同时间分段的空间预测状态学习**——用共享的变跨度转移承接不同分段的真实预测监督，使中间状态不仅产生当前输出，还要能够在共同后续驱动下保留预测能力。这一取向是否成立，取决于实验，而不是取决于命名。下文每一项实验都在为它提供或限制证据。

## 1.3 目前最有价值的四项发现

**第一，在九个留出时间分段上，递归分段监督把分段退化压到了很窄的区间。** 用同一个中间时刻、同一组留出分段做直接路径与分段路径的对照，递归端点训练的误差比值落在 0.992–1.023（IID2856 独立确认集），最坏情形也只比直接路径高 2.75%（dev476 开发诊断集）；而直接端点训练的对照臂在同一组分段上的比值是 1.07–1.32，整体超出门限。**这是本项目目前最强、也最容易复核的信号**：改变计算分段几乎不改变预测，而这并不是标准训练自然得到的结果。

**第二，两条不同前缀路径接上同一段后续天气后，预测质量几乎持平。** 在四个划分上，路径 A（前缀 `[10]`）与路径 B（前缀 `[5,5]`）到达同一中间时刻后共用 10→20 的天气，完整后续窗口的 pooled RMSE 与直达参考 D20 的差距在 −0.62% 到 +0.59% 之间。分段本身不再是预测质量的主要来源——这正是"分段不应主导模型未来"这一要求的直接检验。

**第三，中间状态确实携带后续预测信息。** 把中间状态换成匹配 donor 的状态，后续质量一致变差：主口径（receiver 等权）在四个划分的完整后缀范围上点估计全部为正、自助法区间下界全部大于 0；同一个替换在完整后缀范围内的相对代价是 +1.45% 到 +6.42%。移除状态支路同样使精度显著退化。

**第四，这些稳定性是有代价的，代价被如实记录。** 在标准预测上，递归端点训练（C1）相对直接端点训练（C0R）在每个划分上都略低一点（R²_LC 差 +0.0026 到 +0.0049），相对各划分的最强同协议基线，RMSE 高 4.66% 到 9.30%。分段稳健性换来的是少量一次性精度，而不是精度与稳健性的同时领先。这个取舍关系贯穿全文，是理解后续所有结论的前提。

## 1.4 同一方法的实验链，不是四项独立创新

标准预测、分段比较、共同后缀、状态替换与天气响应构成一条证据链，它们分别约束"能预测""分段可用""可接续""状态有用""天气有效"，缺一项都无法支撑主线。第四至第九章按这条链的顺序展开，第八章集中说明它们如何互相咬合。

# 第二部分 · 方法、实验与结果

## 第二章 · 方法结构与训练逻辑

### 2.1 推理路径

```text
历史影像 + 掩膜 + 历史条件
             │
      Contextformer / PVT-v2 编码器
        ┌────┴────┐
  时距相关上下文先验 P[1:H]   初始空间状态 z0
        │                    │
        │        分段天气 + 地理条件 + 段跨度
        │                    │
        │              共享转移 T
        │                    │
        └────> P[h] + O(z_h) ─────> 预测 NDVI
```

历史序列进入编码器后分成两支：**上下文先验** `P[1:H]` 给出每个未来时距的读出基准；**初始空间状态** `z0` 给出需要被天气推动演化的动态部分。未来天气只进入状态转移路径，解码器把先验与状态相加得到预测。

这里有两处必须说清楚，因为它们直接决定后面实验怎么解释：

**第一，未来的天气是外部驱动，属于后续调用的输入，不是被预测的目标。** 天气需要与时间轴对齐；完整运行状态是 `S_b=(P[1:H], z_b, g, b, 元数据)`，其中 `g` 是地理条件，`b` 是绝对时间偏移——地理条件不是天气条件，两者在状态中的角色不同。

**第二，默认的完整窗口预测并不是纯自回归链。** 在默认路径下，各个时距是从同一个初始状态并行读出的；递归分段是一条额外的训练与运行路径。把整条推理画成逐步自回归会与实际实现不符，也会让后面"变跨度跳跃"的讨论失去意义。

一次转移的具体形式是逐空间块的共享残差 MLP，空间上下文由历史编码器提供。因此本文主张的是**密集空间网格上的预测状态**，不主张每次转移都显式模拟邻域传播或物理扩散。

### 2.2 训练机制：直接与分段两条路径共同接收事实监督

训练时，同一个初始状态沿着不同的分段方案被推进到同一个端点，两条路径都要拟合真实影像：

```text
直接路径：  z0 --T[0,b]--> z_b^direct       --O(P[b])--> 预测 b
分段路径：  z0 --T[0,a]--> z_a --T[a,b]-->  z_b^split --O(P[b])--> 预测 b
```

**C1 与 C0R 的关键差别只在端点监督走哪条路径。** 两臂都保留全时距的直接监督；C1 的额外端点监督经过递归分段，C0R 的额外端点监督走直接路径。两者继承同一个父权重、同一个 seed（42）、同样的世界大小与批大小、同样 14880 步，参数量同为 7.1809 M。这组配对的作用是隔离**训练路径的整体效果**，而不是把差异单独归因给转移算子——两臂在训练中先验与初始状态也可能继续变化。本阶段的显式一致性损失权重为零；父模型预训练阶段使用过未来状态锚定与蒸馏，因此准确的说法是"当前阶段用真实 EO 标签训练"，而不是"整条训练链从未使用教师"。

需要严格区分的是：**C0R 是直接端点监督的对照臂，不是一致性正则臂。** 一个真正的"输出一致性"对照需要在保留 C0R 事实监督的同时另算一条组合路径并施加预测一致性约束——当前代码在直接路径下没有这条分支。因此本轮不把 C0R 当作"简单正则是否足够"的回答，这个对照仍然缺失。同理，把多个前缀路径接到**多个**共同后缀上做联合训练，也不在当前 C1 的实现里。

### 2.3 形式化记号

令 `T_[a,b]` 使用同一条连续天气路径中的对应片段：

```text
z_b^direct = T_[0,b](z0)
z_b^split  = T_[a,b](T_[0,a](z0))
y_b        = P[b] + O(z_b)

共同后缀：
z_c^direct = T_[b,c](z_b^direct)
z_c^split  = T_[b,c](z_b^split)
```

要检验的性质是：两条路径都接近真实观测，且在共同的 `T_[b,c]` 下继续接近真实观测。我们不要求潜向量逐维相同，因此原始状态距离与它对未来读出的影响要分别报告——状态距离大不自动等于失败，状态距离小也不自动等于有效。

### 2.4 术语边界

| 使用 | 中文 | 不偷换成 |
|---|---|---|
| predictive state | 预测状态 | 完整物理真实状态 |
| continuation | 续推 | 无限期准确模拟 |
| variable-span | 变跨度（五日整数倍） | 任意连续时间 |
| shared transition | 共享转移 | 自动满足组合定律 |
| common suffix | 共同后续天气片段 | 单纯相同终点 |
| conditional simulation | 条件模拟 | 已识别的因果反事实 |
| independent retraining | 独立数据重新训练 | 欧洲权重零样本迁移 |

预测窗口是 20 个五日步（约 100 天），跨度以整数步嵌入，先验窗口有限。超出先验范围的窗口应当显式报错，不循环、不补零。因此本文的"可续推"始终限定在**有限窗口内、在所测分段与后续条件下**。

## 第三章 · 标准预测基础：表 1、图 3、图 5

### 3.1 为什么先做这件事

在讨论状态能否接续之前，先要确认这个模型本身是一个可用的预测器。如果它在标准任务上明显不成立，后面所有机制结论都会变成"一个不工作的模型的内部现象"。同时，标准预测也是**代价的度量场所**：分段稳健性如果以过高的精度为代价，就需要在这里说清楚。

### 3.2 比较设计

- **任务与协议**：GreenEarthNet chopped 官方 LC-balanced 评分器；history 130 → forecast 20；四个划分 iid / ood-t / ood-s / ood-st 全部报告。
- **模型范围**：本项目 C1（三个训练 seed 27/42/97），以及同协议重评的四个已发布基线 ConvLSTM 1M、PredRNN 1M、SimVP 6M、Contextformer 6M，外加 Persistence 参照。
- **保留全部已有对照**：不因为某个基线更强就把它移出主表。加粗与胜负判断只在同一划分、同一指标定义内进行。
- **统计量**：均值 ± **样本标准差**（ddof=1，n=3）。这是**种子离散度**，不是置信区间。Persistence 为确定性方法，只有一次评测，因此它没有标准差。

### 3.4 关键现象与意义

**C1 处于已发布基线的同一水平带，但不是最强。** 四个划分的 R²_LC 落在 0.4949–0.5726，与四个基线交叠：在 ood-t 与 ood-st 上高于 ConvLSTM 与 SimVP，在 iid 与 ood-s 上高于 SimVP，但每个划分上都至少有一个基线更高。按 RMSE 排序，C1 在四个划分中分别处于第 4、4、4、3 位（共 5 个方法）。

**种子离散度很小，但这不等于稳定性已被普遍证明。** C1 三个 seed 的 R²_LC 样本标准差在 6.5e-5 到 2.2e-4 量级，比四个基线的种子离散度小一到两个数量级。这值得指出，但它的范围仅限于**这三个 seed、这四个划分**：它说明在这组共享预训练初始化上的后续训练对随机性不敏感，不能外推成"任意初始化或任意环境下都稳定"。基线中 PredRNN 1M 的种子标准差达到 1.1e-2，说明这类比较确实会受到初始化影响。

**Persistence 的 R² 恒为 0 是官方实现下的数学退化，不是"没有正相关"。** 复制最后一次观测意味着预测与真值的时序协方差为零，因此这个参照行的作用是给出 RMSE 量级的下限感觉，而不是一个需要被超越的相关性基线。它也不是理论下界。

**这就是本节的结论与代价。** 标准预测确立了可用性，同时如实暴露了 C1 的精度位置。后续章节要论证的价值必须在**标准预测之外**成立——这正是第四章到第九章的任务。

## 第四章 · 递归监督与分段使用：表 3、表 6A、图 6

### 4.1 为什么做

如果不同时间分段的选取会显著改变预测，那么在多时距查询或天气更新的实际使用中，模型输出就依赖于一个本不该重要的实现细节。这一章检验的是：**训练时把端点监督放在递归分段路径上，是否改变了分段使用的退化程度。**

### 4.2 比较设计

- **配对条件**：C1 与 C0R 同父权重（sha256 前 16 位 `aa98fbd2fa302727`）、同 seed 42、同 world/accum/global batch = 4/2/64、同 14880 步、同机四卡正式运行。唯一主差分是额外端点损失走递归分段还是直接路径。
- **两件事分开报告**：先比标准预测（4.2 节），再比分段稳定性（4.3 节）。开发诊断集 dev476 与独立确认集 IID2856 **分开列出**，不合并成一个结论。
- **分段稳定性的统计量**：对每个留出分段，计算 `composed/direct` 的 **pooled MSE 比值**；门限 1.05 是 **MSE 比值门**。同样的九个分段在三个端点（h=10/15/20，对应 50/75/100 天）上各评估一次。

**范围与限定。** 第一，1.05 是 **MSE 比值门**，不是 5% 的 RMSE 门，两者不可互译；过门是一项能力判定，效应大小要看连续比值，用"9/9 通过"代替效应量会丢掉本结果最有价值的部分。第二，PASS 不等于等价：比值 1.0234 仍然意味着存在约 2% 的 MSE 增加。第三，dev476 是**开发诊断集**，历史协议与聚合口径在结果可见后经过调整，因此它的作用是诊断与展示，独立泛化证据由 IID2856 承担；两者必须分开读。第四，本结果限于已测的九个留出分段与 20 步有限窗口，它不支持"任意分段都稳定"，也不支持"随机分段不可替代"——后一个比较本轮没有做。

## 第五章 · 状态作用与共同后缀：表 4A/4B、表 6B、图 7

这一章是全文的核心。它要回答的是：**在分段几乎不改变输出的前提下，中间状态到底有没有真的承载继续预测所需的信息？**

### 5.1 三个不同的问题，三种不同的度量

这三个度量经常被混为一谈，必须分开：

| 度量 | 回答的问题 | 单位 |
|---|---|---|
| 真实预测误差（pooled RMSE / pooled R²） | 能不能预测得准 | 归一化 NDVI 的误差 |
| 路径输出差异（A 与 B 在同一读出时刻的输出距离） | 两条路径的输出是否相容 | 输出距离 |
| 原始中间状态距离（潜向量 L1） | 状态本身差多少 | 潜空间距离 |
| 状态替换的配对损失差（donor − 正常） | 状态是否被后续路径真正使用 | 配对 MSE 差 |

状态距离大不自动等于失败：两条路径可以到达不同的状态却给出同样好的预测；状态距离小也不自动等于有效。因此本节的结论主要建立在**对真实 GT 的误差**和**替换后的配对损失差**上，状态距离只作为解释性伴随量。

### 5.2 共同后缀实验的完整可比条件

要让"A 与 B 的差异"归因于中间状态，三件事必须同时成立：

1. **两条不同的前缀路径**到达**同一个中间时刻** b=10：路径 A 用前缀 `[10]`，路径 B 用前缀 `[5,5]`；
2. 接上**同一段后续天气** `u[10:20]`，并在**同一读出时刻**比较；
3. 除条件项外，样本身份、掩膜、评分方式完全一致。

这一组条件构成本轮 T6B 的**实验设置**：条件完整可比。设置可比只是前提，结论还要看实际误差与替换效应的大小——这正是下面两节的内容。

需要明确的是，后续轨迹由**独立的多时距查询**产生：从中间状态出发，对每个 k=1..10 用共同天气 `u[10:10+k]` 直接推进 k 步并读出 `prior[10+k]`，而不是逐步递归 rollout。两者是不同的计算过程（`suffix_query_mode=direct_queries` 与 `fixed_step_rollout`），不能混成一条曲线。本轮的共同后缀结果是前者。

范围必须就近说明：**不能写成"所有窗口、所有口径均显著"。** 单终点 h10 上的 ood-st 例外是真实的，且它出现在哪个口径上也必须说清楚。此外，donor 替换在原理上是**输入替换诊断**：它说明模型对中间状态有依赖，不构成完整物理状态的证明，也不是因果反事实——替换后的预测没有对应的真实观测。区间条件于已经固定的 donor 匹配方案，不包含匹配本身的不确定性。

## 第六章 · 天气条件响应：表 5、图 8

### 6.1 为什么做

状态由天气驱动，因此"天气输入是否真的改变了预测"是方法成立的必要条件。这一章同时检验一个更强的说法是否站得住：天气的作用是否**只在**特殊样本（例如热旱）上才明显。

### 6.2 比较设计

在**冻结的热旱子集及其匹配正常对照**上，对同一接收样本换用三种天气：

- `actual`：样本自身的真实天气，**有对应的真实观测**；
- `donor`：匹配对照样本的天气；
- `mean`：该样本目标窗口内自身天气的归一化均值（即归一化天气张量置零，不是物理意义上的"无降水无温度"）。

后两者是**反事实情景，没有观测真值**：它们的输出只能说明"模型会预测什么"，不能当作已被验证的真实环境后果，也不能计算相对原 GT 的"反事实准确率"。所有 ΔLoss 都在**完整 20 步目标窗口**上按有效像素求掩码 MSE，**不是第 20 步单帧误差**——历史字段名 `endpoint_fidelity` 是旧命名，与此不符。

## 第七章 · 运行成本与状态复用：表 7、图 9

### 7.1 为什么做

"可复用状态"是一个成本主张，不是精度主张。潜在用法包括：对不同查询时距复用历史编码；在天气预报更新后从已保存的状态重新分支；在多个给定天气情景下比较未来。这些操作的实际开销必须测量，"可缓存"不能直接写成"更快"。

### 7.3 关键现象与意义

**复用真正节省的是什么。** 节省的是**历史编码与共享前缀的重复计算**（`history_encoding + shared_prefix`），它在 B 个查询之间被摊销；两条路径在 `suffix_per_branch` 上完全相同。因此收益随查询数增长：B=1 时两条路径等价（1.00×），B=8 时成本模型给出 7.30×。这是"状态可以被复用"这一说法唯一站得住的量化形式。

**为什么本轮不报单一倍率。** 第一，比值随 B 变化，任何单一数字都只是某个 B 的取值，不能代表这条路径的一般性质。第二，也是更重要的，适配器路径的每一次 `advance()` / `decode()` 都会执行一次**全量 state-dict 哈希校验**（单次中位 33.35 ms，一次端到端共 10 次），而重编码路径支付的次数只有它的四分之一。适配器端到端 371.15 ms 与纯计算副本 34.40 ms 之间的差额，主要来自这项身份校验策略，**不是算子效率差异**。把它写成"适配器比纯计算慢 N 倍"会是错误结论。

**实测与推算必须分开。** 表中的分阶段成本是**实测**；随 B 变化的比值是**成本模型推算**，两者在本轮已分别标注，不应合并成一个"实测加速比"。

**范围与限定。** 第一，运行时测量是受限测量：单机单卡、单样本、batch 1、fp32、共享节点，测量时段内有其他计算进程（已记入 `metrics/T7_c1_runtime.json` 的 `contention` 字段）。第二，四条查询使用**完全相同**的一段真实未来天气，因此两条路径的唯一差别就是"历史与前缀是否重算"；代价是这次测量不包含"多个查询天气各不相同"的情形。第三，训练峰值显存历史上没有记录，本轮留空，不用当前重测代替历史峰值。第四，同更新次数不等于同计算量：C1 的端点分支调用期望值是 8.005、C0R 恒为 3，因此两臂的墙钟差异只作成本记录，不作效率结论。第五，**普通缓存收益不等于独特算法优势**——历史编码缓存对任何具备该接口的实现都成立。

### 8.2 证据链为什么是互补的

这条链的顺序不是编排上的偏好，而是逻辑上的必要：

- **标准预测**建立可用性，同时给出代价的度量。没有它，后面所有机制结论都缺少参照。
- **分段稳定性**回答"训练路径是否真的改变了行为"。它的说服力来自对照臂并不弱：C0R 的标准预测还略好一点，所以差异不能被解释成"整体训练质量"。
- **共同后缀**把分段稳定性从"端点图像相似"推进到"在共同后续驱动下继续预测"。这一步是必要的，因为终点相似可以来自两条路径犯了同样的错误，而共同后缀下的持续误差无法这样解释。
- **状态替换**把"路径相容"和"状态有用"分开。分段稳定可以来自一个从不使用状态支路的模型；替换实验直接检验状态是否被后续路径依赖。
- **移除臂**补充说明这条支路在单次预测中也被使用，与替换实验形成"训练时用、推理时也用"的互补。
- **天气响应**检验驱动是否真的进入预测，而不是一个被忽略的输入。
- **成本**把整件事落到可用性上：能力的代价是多少，复用在什么条件下划算。

### 8.3 一句话总结核心主张

> 在 GreenEarthNet 第一数据集上，把端点监督放到递归分段路径上训练，可以在几乎不改变一次直达预测质量的前提下，使预测对时间分段的选择基本不敏感；到达中间时刻的状态携带与样本相关的后续预测信息，在接上共同后续天气后仍能继续准确预测。这一能力的代价是标准预测上小幅但方向一致的精度下降。

## 第十章 · 统计口径与敏感性分析

### 10.1 两条口径不可互换

| 口径 | 定义 | 用在哪 | 不能做什么 |
|---|---|---|---|
| 官方 **LC-balanced** | GreenEarthNet 官方 chopped 评分器，按地类平衡后在官方层次汇总；`r²_LC` 是官方时间 Pearson 相关系数平方 | 表 1、表 3、表 4A，以及表 5 的子集精度 | 不能与 pooled 数字比较或换算 |
| **pooled** | 合并充分统计量后计算：`RMSE_pool = sqrt(ΣSSE/Σn)`，`R²_pool = 1 − ΣSSE/SST`，`SST = Σy² − (Σy)²/n` | 表 6A、表 6B、表 3 的配对 bootstrap | 不能替代官方指标作为主表口径 |

`r²_LC` **不等于** `1 − SSE/SST`。本文不提供任何口径换算后的数字。

### 10.2 区间的含义与边界

- **表 1 的 ± 是样本标准差（ddof=1，n=3），不是置信区间。** 它度量三个训练 seed 之间的离散度。C1 单 seed 的行不填 ± 0 冒充无方差。
- **表 3 的配对 bootstrap** 按空间组（优先 Sentinel-2 tile 码，缺失时回退到 0.1° 经纬度网格）配对重采样，同一次重采样同时作用于两臂；B=2000，seed=20260910。主分组保持已报告数值不变，另附 0.5° 粗网格作为敏感性：四划分结论方向一致（空间组数在 0.5° 下变为 iid 80 / ood-t 77 / ood-st 399 / ood-s 454）。
- **表 4B 的三口径**对同一数据的加权方式不同，因此数值不同是预期的，不是矛盾；主口径在全部划分与范围上作为头条口径报告，包括对它最不利的情形。区间条件于已固定的 donor 匹配方案。
- **表 5 的三种区间单位**（样本级配对、地理组整簇、匹配对照簇）符号结论一致，但不可互相替代。
- **表 3 的 CI 跨 0 不等于非劣。** 本对照从未定义非劣性边界，因此不做非劣性检验；区间跨 0 只表示该划分上方向不可判定。
- **自助法分布不能当作真实效应的后验概率。** `P(Δ<0) = 0.8005` 之类的数字是重采样频率，不是"效应为负的概率为 80%"。
- **种子离散度与抽样置信区间是两件事**，必须分列。三种子可以报 mean ± std，不能因为评测像素很多就把单模型训练的不确定性说成很小。

### 12.4 结论的适用边界

综合全文，本轮的结论成立范围是：

- **数据集**：GreenEarthNet / earthnet2021x 第一数据集，四个 chopped 划分。
- **窗口**：20 个五日步（约 100 天）的有限预测窗口，不延伸到更长时距。
- **分段**：在所测的九个留出分段与共同后缀条件下，不推广到任意分段。
- **种子**：主要机制结论来自单 seed（42）的配对对照；标准预测有三 seed。三 seed 的离散度小不能外推为所有初始化或环境下的稳定性。
- **天气**：天气响应证据限于冻结热旱子集与匹配正常对照；替换情景没有观测真值。
- **成本**：运行时数据来自受限测量；成本模型为推算。普通缓存收益不构成独特算法优势。
- **状态解释**：本文不使用"任意分段""连续时间""完整物理状态""真实反事实"这类未经检验的表述，也不推断潜在维度对应具体物理量。

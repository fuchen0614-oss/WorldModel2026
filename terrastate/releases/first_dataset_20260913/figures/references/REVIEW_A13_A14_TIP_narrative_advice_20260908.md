**2．最可能被审稿人击中的五个问题。**

| 审稿反问 | 当前证据能回答什么 | 仍需解决什么 |
|---|---|---|
| 直接与分段路径一起接受真实监督，是否已经有人做过？ | C1 确实实现了这种训练，且有同参数 C0R 对照 | 正面讨论 Deep-OSG LISG；不能把这一原则单列为首创 |
| RNN 本来就能续推，你们额外提供什么？ | C1 支持跨度条件化的跳跃转移 | 与固定步长递归比较预测质量、转移调用和真实耗时；证明跳跃带来实际收益 |
| 状态是可复用的，还是缓存了一整段未来预测？ | 完整运行状态可合法包含 prior 与 z | 明确有限窗口、上下文依赖，并证明 z 在当前图像之外保留后续有用信息 |
| 两条路径精度相近，就意味着状态等价吗？ | 已有分段端点误差稳定的信号 | 两条路径可能犯不同错误；需要共同后续事实预测，不能只比两个标量 RMSE |
| 图像预测比已有方法差，为什么值得采用？ | 新能力可能构成精度之外的价值 | 给出公平的能力—精度—成本证据，及密集空间状态的必要性 |

最重要的文献发现是 **Deep-OSG §3.2 的 LISG**：它已经使用纯数据的两步监督，使直接和组合路径拟合同一真实终点，间接改善组合性。A13 只写“自治动力系统设置不同”不足以完成区分。这不等于两个项目相同，但意味着“直接—分段事实监督”本身不宜被包装成新原理。[Deep-OSG 原文，式 15–16](https://arxiv.org/html/2302.03358v2)。

另外，PlaNet 已包含图像潜动力学和多步观测/潜状态训练；VegSim 已包含天气驱动潜状态递推和情景模拟，但其目标是 minicube 平均 NDVI 标量；EO-WM 已讨论天气条件世界建模与多光谱生成。这些工作分别覆盖了“训练未来状态”“天气世界模型”“超越重建评价”的一部分叙事。TerraState 的差异需要由隐藏空间状态的时间推进能力建立。[PlaNet](https://proceedings.mlr.press/v97/hafner19a.html)；[VegSim](https://arxiv.org/html/2606.21961v1)；[EO-WM](https://arxiv.org/html/2606.27277v1)。

固定步长模型的挑战尤其重要：沿相同输入依次执行十次相同更新，分成两次调用各执行五步，底层运算并没有改变。故“能保存/恢复、能继续”不是独有贡献。TerraState 值得研究的是：用不同跨度的跳跃替代细步递归后，能否保持预测质量和后续能力，并获得实际查询收益。如果最终没有耗时优势，也没有其他经对照验证的任务收益，只有“接口更灵活”，当前精度代价很难解释。

**4．推荐主旨：从一次性预测，推进到对计算分段稳健的空间预测记忆。**

建议的一句话科学问题：

> 在部分可观测的遥感影像序列中，如何学习空间预测状态，使天气条件预测在改变推进跨度后仍保持准确，并保留后续预测需要的信息？

对应当前代码、不过度预告结果的表述：

> TerraState 在上下文先验上学习天气驱动的空间动态状态，通过共享变跨度转移与直接—分段联合观测监督，改善有限预测窗口内的分段预测稳定性，并检验中间状态的后续预测能力。

建议题目：

**TerraState: Learning Reusable Spatial States for Weather-Conditioned Vegetation Forecasting**

若多种子、留出分段和共同后缀均形成充分证据，可使用更强版本：

**TerraState: Learning Temporally Composable Predictive States for Vegetation Forecasting**

两个题目都需要结果支撑；当前阶段不能把 Reusable/Composable 当作已经证实的标签。如果只确认了端点稳健性，可暂用 `Partition-Robust Vegetation Forecasting`。正文可继续把 TerraState 归入天气驱动遥感世界模型研究。

这里最有价值的“拔高”是解释**当前图像预测正确为什么还不够**。当前默认每个 patch 的 256 维状态经线性头变为 16 个 NDVI 值，读出矩阵秩至多 16，因而至少有 240 维方向不能由当前输出直接确定。这是代码层面的非唯一性，不代表这些方向已经存了有效记忆。[线性读出定义](<D:/Mine Program/codexwork/CVPRAAAI投稿/WorldModel2026v2/terrastate/models/plan_b_b4.py:152>)。

一个自行构造的解释性反例是 `O(a,b)=a`，`T_w(a,b)=(a+bw,b)`。两个状态具有相同 a、不同 b，当前读出相同，共同天气 w 下的未来读出却不同。它解释了共同后缀实验的必要性，也说明端点一致不能推出预测状态充分。此例是论证工具，不是本模型的物理假设或新定理。

对天气驱动问题，应比较按原顺序拼接的同一外部驱动路径；不能从自治半群类比出天气片段可交换。建议使用“在所测分段和后续条件下的预测相容性”，慎用严格半群、充分状态、物理一致性等更强术语。

A13B 按任务匹配度优先 Africa、保留 DeepExtremeCubes 的决策逻辑可以沿用。当前更重要的是第一数据上的机制是否成立，暂不建议为降低下载成本改用任务差异很大的分割数据。未来第二数据至少应复验 C1/C0R 的分段与后续能力，不能只增加一张普通预测表。

对“当前输出之外的信息”，建议增加一个有区分力的控制，优先级高于重复 alpha=0：训练一个跨段只能携带当前预测图的瓶颈模型，保持相同 prior、天气、地理及时间条件，给予相当容量、监督和预算，再比较后续事实误差。它比任意 donor 替换更接近要证明的命题。

低成本补充诊断可利用线性读出：固定同一权重，令 `P=W†W`，考察 `z+(I-P)v`。当前读出理论上不变，观察后续是否改变及事实损失是否恶化。必须验证数值读出误差、控制扰动幅度和范数，并说明离分布扰动也能引起变化；该诊断不能单独证明有效记忆或物理因果。

若突出 TIP 的图像方法价值，可补一个空间池化后广播的动态状态/残差配对对照，并给出局部变化的真实误差图。重点是检验空间异质状态是否有用；单纯画高分辨率地图并不能证明动态模型贡献了空间细节。梯度或局部变化指标可作解释性补充，不宜临时堆一批对模型有利的新指标。

**7．如果允许大改，建议有条件地改训练问题，而不是先堆结构。**

第一层是现在即可做的叙事重构，不改网络：把中心改成变跨度查询下的预测状态质量，减少世界模型身份、接口验收和 Q3 极端天气包装。用现有 C1 检验它能承载多强主张。

第二层是核心后缀结果不足时的候选新方法：训练时从不同前缀路径得到中间状态，再对多个后续时距施加真实影像监督；在天气顺序不变的前提下扩大训练分段，并保留未参与调参的确认分段。其目的在于直接训练后续使用能力，而非只压小潜状态距离。这仍与多步观测监督存在联系，需要证明比等标签、等预算的普通递归更有效。它尚未实现，不能提前归入 C1 的贡献。

只有当有限 prior 成为关键瓶颈，且确实要主张更长窗口的模拟，才值得第三层结构重构：研究不依赖预存完整未来 prior 的运行状态或可延展读出，以及与之匹配的时间条件。天气 GRU 跨段记忆是否需要保留也属于新模型假设，不能当作接口修补悄悄加入。此路线成本更高，不能靠更换标题完成。

若 C1 在共同后缀、固定步长和简单正则对照中没有优势，我不建议只加第二数据然后直接投 TIP。应先改变方法或降低主张。反之，若同等成本下得到明确的分段/后续预测收益，即使标准单次预测没有全面第一，也有可以认真论证的价值。录用概率无法由现有材料可靠量化。

**9．给 A14B 的几条必要补充，防止实现出来的实验回答错问题。**

1. **C0R + 输出一致性不能只打开现有 lambda。** 当前 `factual_path=direct` 时，损失中的 `y_fact` 与 `y_dir` 是同一直接路径，现有一致性项为零。必须额外算组合路径，并验证损失非平凡、梯度有效。[代码位置](<D:/Mine Program/codexwork/CVPRAAAI投稿/WorldModel2026v2/terrastate/models/terrastate_candidate_c.py:403>)。
2. **不要认为配对会自动消除空间相关。** 旧 Q4 代码有这一注释；配对差值仍可能在同 tile 内相关。新方法内/方法间主要 CI 都应按空间组配对重采样；不把旧 CI 改名。[旧注释](<D:/Mine Program/codexwork/CVPRAAAI投稿/WorldModel2026v2/terrastate/eval/eval_terrastate_candidate_c_q4.py:49>)。
3. **路径差距与事实误差必须说明掩膜。** 旧 `delta_y` 是全图未掩膜差距，事实误差使用有效云/地类掩膜。可同时保留全图差距和相同有效区差距，不能直接当作同口径比例。[路径差距](<D:/Mine Program/codexwork/CVPRAAAI投稿/WorldModel2026v2/terrastate/eval/eval_terrastate_candidate_c_q4.py:304>)。
4. **资格与工程失败分离。** 当前 `eligible` 含 `isfinite(mse)`，预测异常可能进入资格过滤；新流程应独立记为失败。常量 GT 的 RMSE 仍有定义，也不应机械沿用 R² 的 `SST>0` 筛选。[资格代码](<D:/Mine Program/codexwork/CVPRAAAI投稿/WorldModel2026v2/terrastate/eval/eval_terrastate_candidate_c_q4.py:623>)。本次没有证据表明历史数值已因此受影响，属于需核验的实现风险。

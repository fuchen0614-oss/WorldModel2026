# 第一部分 主旨、科学问题与方法定位

## 1. 一句话主旨

> TerraState 是一个天气驱动的遥感世界模型：它从不完整的历史影像中学习显式空间预测状态，通过共享的变跨度转移与直接—分段联合事实监督，使中间状态继续承担后续预测，并检验同一天气路径下不同时间分段的预测相容性。

口语解释：我们不是只问“这一次未来猜得准不准”，还要让已经推演到一半的状态接着用，而且不能仅仅因为改变了计算分段，未来就明显变样。

## 2. 科学问题

> 在稀疏、部分可观测的高分辨率地球观测序列中，能否构建一个天气驱动的遥感世界模型，学习真正面向未来的空间预测状态，使不同时间跨度的转移能够近似组合，并使不同推进路径得到的中间状态继续可靠地承担后续预测？

这里“真正面向未来”不是声称理解了完整物理世界，而是可检验的功能要求：状态保留的信息必须对后续真实影像预测有用。

### 2.1 为什么有科学意义

观测只是地表的部分投影。相同 NDVI 可以对应不同的生长阶段、先前水分压力和未来变化潜力；云遮挡进一步使单帧无法决定未来。因此，历史形成的预测状态应保留当前输出之外、后续预测需要的信息。此处是建模动机，不是已证实模型学到了土壤水分等具体物理变量。

在给定初始条件和同一天气路径的模拟中，人为选择一次推进 20 步还是先 10 步再 10 步，不应成为预测大幅变化的主要原因。对受驱动动力系统而言，可组合的演化具有理论动机；对有限维、部分可观测、学习得到的遥感状态，它只是需要验证的近似性质，并非 NDVI 必须严格满足的定律。

这同时提出两个不同问题：
- **组合问题**：不同计算路径到达同一时刻，输出是否相容？
- **预测记忆问题**：这些中间状态是否仍保留能支持下一阶段预测的信息？

终点图像相似只能回答前者的一部分。必须接上共同后续天气，才能更直接检验后者。

### 2.2 实际价值与需要付出的代价

潜在使用方式包括：对不同查询时距复用历史编码；在天气预报更新后从已保存的状态重新分支；在多个给定天气情景下比较未来。要通过 Fig. 9 / Table 7 测量这些操作的实际成本，不能把“可缓存”直接写成“更快”。

提供真实未来天气的实验属于给定驱动的条件预测，不等于真实部署时提前获得了准确天气。天气预报误差、未观测管理活动和观测噪声仍限制应用。

当前没有新的影像同化模块，所以“天气更新后续推”不等于“新卫星影像到达后自动更新状态”。当前先验有有限预测窗口，所以也不等于无限期模拟。

## 3. 世界模型身份与独特性

本文采用的操作性描述是：从历史观测推断内部状态，在外部驱动下演化，并读出未来观测的领域模型。它不要求具身动作、语言模型或扩散模型；也不因为具备这三块结构就自动证明科学贡献。

**研究对象是世界模型；可组合、可续推的空间预测状态是本工作的具体方法问题。**

本文不主张“首次训练潜状态”“只有我们把状态放进训练”。PlaNet 等潜动力学模型早已使用多步训练；VegSim 等遥感研究也有天气驱动的潜状态推进。真正需要定位和验证的是：

> 在密集遥感图像预测中，以共享变跨度转移承接不同分段的真实预测监督，使中间状态不仅产生当前输出，还能够在共同后续驱动下保留预测能力。

这一定位的强度取决于实验：需要胜过直接训练、固定步长递归、简单一致性正则和相当计算量的对照。不是把若干已有模块组合后，靠世界模型名称获得创新性。

### 3.1 建议题目

**TerraState: A Weather-Driven Earth Observation World Model with Composable Predictive States**

中文：TerraState：具有可组合预测状态的天气驱动地球观测世界模型。

“Composable（可组合）”是拟验证的题目主张。若共同后缀实验不支持，不可仅保留这个题目而隐藏结果。

### 3.2 摘要组织，不预填成功结论

高分辨率植被预测需要从稀疏、受云遮挡的历史观测中推断地表未来。固定窗口的预测精度不能单独说明内部状态能否在不同时间分段下持续承担预测。为此，我们提出 TerraState，一个天气驱动的遥感世界模型。模型以显式空间状态和共享变跨度转移组织模拟，并联合使用直接路径与分段路径的真实未来监督。我们同时评估标准图像预测、状态贡献、天气条件响应以及不同中间状态的共同后续预测，以检验状态的可复用性。最终结果段应填写多种子、强对照和独立数据证据，准确说明预测质量与模拟灵活性之间的收益和代价。

## 4. 实际结构，不把规划写成代码事实

```text
历史影像 + 掩膜 + 历史条件
             |
      Contextformer / PVT-v2
        /                 \
时距相关上下文先验 P[1:H]   初始空间状态 z0
        |                  |
        |      分段天气 + 地理 + 段跨度
        |                  |
        |            共享转移 T
        |                  |
        +------> P[h] + O(zh) ------> NDVI 图像
```

准确的运行状态至少是 `S_t=(P[1:H], z_t, g, offset, shape/contract metadata)`，不是只保存 `z_t`。未来天气是后续调用的外部输入，需要时间对齐；不必把所有未来天气永久塞进状态。

代码审计基线：
- C1 与 C0R 继承相同模块，约 7.18M 参数，不靠增加参数制造差异。
- 上下文先验不接收未来天气；未来天气通过状态转移路径影响输出。这一通路隔离值得清晰画出。
- C1 与 C0R 都保留全时距直接预测监督；C1 的额外端点监督走递归分段，C0R 走直接路径。
- C1 当前阶段一致性损失权重为零；其父模型预训练使用过未来状态锚定/KD，不能称整个训练链从未使用教师。
- 转移主要是逐空间块的共享残差 MLP；历史编码器提供空间上下文。不能声称每次转移都显式模拟邻域传播。
- 当前典型预测窗口为 20 个五日步。整数跨度嵌入不等于连续时间算子。
- 现有 `test_candidate_c_resume.py` 是训练恢复测试，不能据此认定运行状态保存与续推已正式验收。

形式化表达：令 `T_[a,b]` 使用同一连续天气路径中的对应片段。

```text
z_b_direct = T_[0,b](z0)
z_b_split  = T_[a,b](T_[0,a](z0))
y_b        = P[b] + O(z_b)

共同后缀：
z_c_direct = T_[b,c](z_b_direct)
z_c_split  = T_[b,c](z_b_split)
```

先检验两条路径都接近真实观测，再检验两者相容。不要求潜向量逐维完全一样；保留原始状态距离，同时观察其对共同未来读出的影响。

# 第二部分 证据与指标契约

## 6. Q1–Q4 分工

| 问题 | 回答什么 | 不能由它单独推断什么 |
|---|---|---|
| Q1 预测 | 生成的未来图像是否接近事实 | 有完整世界状态、可以可靠无限续推 |
| Q2 状态 | 动态状态是否承担输出并携带后续有用信息 | 状态每一维都可物理解读 |
| Q3 天气 | 模型是否有效利用给定天气、如何产生条件差异 | 替换天气下的因果反事实是真实的 |
| Q4 组合 | 不同分段是否保留预测质量、共同后缀能力 | 潜向量必须完全相同、普通递归模型不是世界模型 |

四问是同一方法的证据链，不是四项互相独立的方法创新。

## 7. 指标名称必须分清

| 标记 | 定义与用途 | 注意 |
|---|---|---|
| r²_LC | 官方时间 Pearson 相关系数平方，经像素、cube、地类汇总 | 不等于 1-SSE/SST；保留官方常量处理约定 |
| RMSE_LC | 官方时间像素 RMSE 再按官方层次汇总 | 不等于全像素合并开根号 |
| R²_pool | 对指定有效集合合并充分统计量后的 1-SSE/SST | 明确 SST 为合并集合中心化；不可平均 per-cube R² 替代 |
| RMSE_pool | sqrt(合并 SSE / 合并有效计数) | 用于 Q4 端点/续推，报告集合与掩膜 |
| ΔLoss | control 损失减 actual 损失 | 必须注明窗口、掩膜、样本范围和单位 |
| 输出路径差距 | 两路径同终点预测的 RMSE | 与对 GT 的误差同时报告 |
| 原始状态差距 | 归一化潜向量距离 | 不把大距离自动判成失败，也不删除不利原始结果 |

逐时距图不能把“整段时间相关性 r²”原封不动当单时刻指标。Fig. 5 主图用逐时距 masked RMSE；若画 R²，需明确它是单时刻跨有效像素的 R²_pool。

历史 Q2 的官方整体差值与 paired mean（配对样本均值）估计对象不同，其 CI 不能互相挪用。新的推断优先按空间 tile 聚类配对 bootstrap；历史 CI 原样标明，不改成没做过的聚类 CI。

G1、G3 的低成本导出可以穿插，但 G2 决定核心论点是否值得进入大规模训练。已经看过的锁定测试集只能作历史复现，后续调参不得反复利用它伪装留出确认。

## 27. 科学验收，不许为了通过而改尺子

值得继续：C1 在真实误差仍可接受的条件下，跨分段/共同后缀优于 C0R；中间状态的替换具有可解释的后续影响；收益经配对种子、简单对照及资源核算后仍成立。

需要定位或方法调整：C1 只让终点图像相似，后续却明显失效；简单固定步长或一致性正则在相关精度、灵活性和成本上全面替代 C1；精度代价大到无法支持实际任务；状态主要靠 prior 旁路且续推没有新增价值。

这些情况不能靠增加第二数据、图表数量或换一个显著性门解决。先排除实现错误，再修改训练/结构；新方法必须命名新 run，不覆盖旧 C1。

## 28. 主张纪律与术语

| 建议词 | 中文 | 不应偷换成 |
|---|---|---|
| predictive state | 预测状态 | 完整物理真实状态 |
| continuation | 续推 | 无限期准确 |
| variable-span | 变跨度 | 任意连续时间 |
| shared transition | 共享转移 | 自动满足组合定律 |
| factual supervision | 真实观测监督 | 整个预训练链无教师 |
| common suffix | 共同后续天气片段 | 单纯相同终点 |
| conditional simulation | 条件模拟 | 已识别的因果反事实 |

## 29. 主要依据

- [GreenEarthNet / CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/html/Benson_Multi-modal_Learning_for_Geospatial_Vegetation_Forecasting_CVPR_2024_paper.html)：预测任务与同协议基线。
- [PlaNet / ICML 2019](https://proceedings.mlr.press/v97/hafner19a.html)：已有潜动力学与多步训练，不主张首次。
- [Deep-OSG](https://arxiv.org/abs/2302.03358)：算子组合的相关研究；其自治动力系统设置不等同于本任务。
- [VegSim，预印本](https://arxiv.org/abs/2606.21961)：天气驱动潜状态情景模拟，任务粒度需区别。
- [EO-WM，预印本](https://arxiv.org/abs/2606.27277)：多光谱概率世界建模，不应说同行只用自定义指标。
- [VegeDiff / 官方仓库](https://github.com/NJU-LHRS/Official_VegeDiff)：高分辨率概率预测的直接相关基线候选。
- [TIP 范围](https://signalprocessingsociety.org/publications-resources/ieee-transactions-image-processing/about-transactions-image-processing)、[作者指南](https://signalprocessingsociety.org/publications-resources/information-authors)：方法问题与图像时序建模契合，但没有“达到图表数量就能发表”的标准。

最终结论：这是一个有科学立足点的遥感世界模型研究问题；当前证据足以支持继续完善，但尚不能把“共同后缀预测充分性、跨种子稳健、独立数据有效”写成已成立结果。

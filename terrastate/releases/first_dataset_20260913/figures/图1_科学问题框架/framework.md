# 图1：科学问题框架（文字版）

相同历史观测 + 相同外部天气
        │
        ├── 时间分段方案 A ──> 中间状态 z_A ──┐
        │                                      ├──> 共同后续天气 ──> 后续输出 A
        └── 时间分段方案 B ──> 中间状态 z_B ──┘                  └──> 后续输出 B

需要分别回答两个问题：

1. 当前输出是否准确：比较每条路径输出与真实观测；
2. 后续能力是否一致：固定共同后续天气，比较不同中间状态产生的后续输出。

两者不是同一问题。普通预测误差相近，不能代替状态可复用性或共同后缀一致性证据。
本框架不画虚构结果，也不使用“真假世界模型”的分类。

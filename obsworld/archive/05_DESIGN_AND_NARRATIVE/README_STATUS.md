# 设计与叙事文档状态

本目录保留少量早期主线、字段设计和 Stage 1.5 正式执行方案，用于复盘思想来源。

它们包含三种不同层级的信息：

- 原始研究动机：为什么需要从观测特征进一步构造状态；
- 当时的设计假设：FiLM、\(\phi\)、跨模态对齐、泄漏约束；
- 训练前计划：验收门槛、训练步数和可能的回滚路线。

部分早期文件包含后来被放弃或证伪的表达，例如完整成像不变性、旧 Plan A、把低 nuisance loss 等同于非线性解耦成功。继续研究时必须先读：

- `../00_START_HERE/RESULT_TRUTH_AND_LIMITATIONS.md`
- `../00_START_HERE/CONTINUATION_NARRATIVE.md`

本目录服务于“理解为什么这样设计”，不应替代当前代码与最终 30k/60k 结果。
